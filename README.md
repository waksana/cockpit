# Cockpit

**在浏览器里，与 Copilot 一起工作。**

Cockpit 为 Copilot 提供一个清晰、专注的工作区。你可以在不同项目的会话之间切换，
继续讨论，阅读回复，也可以展开查看工具调用和子 Agent 的工作过程。

让答案保持易读，让过程随时可查，把注意力留给正在做的事情。

## 用 Cockpit 做什么

- **在多个项目间继续工作。** 搜索、切换会话，回看讨论，从已有上下文继续。
- **专注阅读，也能追溯过程。** 回复像文档一样呈现；思考、工具输入输出和子 Agent 按需展开，不必让所有细节挤满屏幕。
- **保持对工作的掌控。** 查看正在执行的步骤，回答 Agent 的问题，追加待处理消息，或停止当前执行。
- **选择合适的能力。** 调整会话使用的模型、思考力度和上下文长度，管理可用工具与技能。

## 为自己的工作而设

Cockpit 面向在自己机器上使用 Copilot 的个人用户。它不是另一个聊天账号，
也不是团队协作平台，而是你与 Copilot 工作时的一扇浏览器窗口。

请只在可信的机器和项目上使用；需要远程访问时，按安装文档设置访问保护。
项目仍在持续完善中，当前版本的变化可在[发行说明](https://github.com/waksana/cockpit/releases)中了解。

## 安装

把下面这段话复制给你的 Agent：

```text
请阅读 Cockpit 的安装文档：
https://github.com/waksana/cockpit/blob/main/docs/DEPLOY-PORTABLE.md

按照文档在这台机器上安装并启动 Cockpit。
需要我完成登录或确认操作时请告诉我，完成后给我访问地址。
```
