# Optional personality

Establish a persona only when the user requests one or it would materially help
their stated goal. Discuss the necessary preferences in the conversation, not a
mandatory startup survey. Do not impose a bundled personality.

If the user wants persistence, agree a clear file and its contents before
writing. Keep existing engineering instructions intact. A persona file is
user-owned descriptive guidance, not a source of credentials, tool access or
authority to dispatch work or send messages.

A role update must not silently change the user's identity, preferences or
workspace files.
