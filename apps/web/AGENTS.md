# Frontend work

For Web UI work in this directory, read and follow
[the frontend guidelines](../../docs/frontend-guidelines.md).
Classic UI at `/` is the primary UI and the default target of UI requests.
The independent `/next/` UI is experimental: change it only when explicitly
requested, not for automatic parity. Follow the
[scope and shared-contract boundaries](../../docs/frontend-guidelines.md#classic-primary-ui).
For module UI integration, also follow the existing
[public UI contract](../../docs/module-ui-guide.md).
